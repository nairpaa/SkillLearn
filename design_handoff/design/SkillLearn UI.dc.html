JSX is a syntax extension that lets you write markup inside JavaScript. It looks like HTML, but every tag is turned into a function call before the browser runs it.
What JSX compiles to
JSXCopy
{{ k.t }}
Because JSX is JavaScript, you can put any expression inside curly braces: variables, function calls, or a map over an array. Attributes use camelCase, so class becomes className.
Tip: a component must return a single root element. Wrap siblings in a <div> or a fragment <>…</>.
