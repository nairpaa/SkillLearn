ARTICLE · 6 MIN READ JSX explained Rizky Pratama · React Fundamentals
JSX is a syntax extension that lets you write markup inside JavaScript. It looks like HTML, but every tag is turned into a function call before the app runs it.
What JSX compiles to
JSX
{{ k.t }}
Because JSX is JavaScript, you can put any expression inside curly braces. Attributes use camelCase, so class becomes className.
Tip: return one root element. Wrap siblings in a <div> or a fragment.
