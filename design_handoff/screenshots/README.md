# Screenshots

Full-length captures of every screen and key state, taken from the prototype in `../design` with the demo user (Alya Rahma, default favorites).

- **Web**: laid out at 1280 px, exported at 909 px wide (≈0.71×). For crisp 1440@2x images run `figma/capture.mjs`.
- **Mobile**: 390 px column at 1×, full scroll length (sticky header/tab bar shown in flow at the end of the page).
- File name = `<platform>__<screen id>-<name>__<state>.png`, same IDs as `../screens.json`, the README and Figma frames. The Figma importer plugin accepts these files directly.
